Read the privacy details.

Screen Landmark Lens asks you to select a window before capture.

Window captures

After recognition, Lens returns labels and directions, not capture pixels.

The app asks you to choose a window before each capture.

Local preferences

You can set a voice speed. The sample project uses a separate demo setting.

Choosing Start for real clears that demo setting and restores your regular app setting.

Website

The website has no advertising cookies, behavioral analytics, or third-party scripts. Its service worker caches public pages for offline use.

The landing page may ask GitHub’s API for release details once per hour in each browser. GitHub receives ordinary request data for that check. The sample demo never makes that request.

Your choices

You can use all shipped label-finding features without an account or purchase. You can change screen-capture permission in your operating-system settings.

Contact

For privacy questions, open an issue in the public project repository. Do not include sensitive captures.
