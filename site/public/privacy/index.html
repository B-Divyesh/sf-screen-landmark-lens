Plain-language policy · September 1, 2026

Your screen stays on your device.

Screen Landmark Lens processes the window you explicitly select on your own computer.

Window captures

A capture stays in memory only while the bundled OCR engine reads it. It is not written to your documents, sent to us, used for training, or retained after analysis finishes. Lens never captures the full screen unless the window you choose is itself full-screen.

Local preferences

The app stores your voice speed locally. The sample project uses a separate demo storage key. Choosing Start for real clears that demo preference and restores your regular app preference.

Website

The website has no advertising cookies, behavioral analytics, or third-party scripts. Its service worker stores public page assets so the explanatory pages can reopen offline. The landing page may ask GitHub’s API for current release metadata once per hour in each browser. GitHub receives ordinary request data for that check. The sample demo never makes that request.

Your choices

You can use all shipped wayfinding features without an account or purchase. Screen-capture permission can be revoked in your operating-system settings at any time.

Contact

For privacy questions, open an issue in the public project repository. Do not include sensitive captures.

Screen Landmark Lens is a local visual landmark finder by Param Factory.
